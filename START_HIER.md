# 🎮 Java Programmieren - Alle Lernpfade
## Modulares Lernprojekt für Anfänger bis Fortgeschrittene

Willkommen! Dieses Projekt enthält **5 separate Lernpfade** für Java und Minecraft-Modding.

---

## 📚 Die 5 Phasen

Jede Phase ist eine **eigenständiges Projekt** - du kannst einen neuen Ordner in VS Code öffnen.

### 🟢 **Phase 1: Java Basics** (4-5 Wochen)
📁 Ordner: `01-java-basics`

**Inhalt:** Grundlagen der Java-Programmierung
- System.out.println()
- Variablen (int, String, double, boolean)
- Operatoren (+, -, *, /)
- if/else Bedingungen
- for Schleifen
- Arrays
- Funktionen

**Abschlussprojekt:** 🎯 `ABSCHLUSSPROJEKT.md` - Minecraft Character Generator
**Nach dieser Phase:** Kannst du einfache Java-Programme schreiben

---

### 🟡 **Phase 2: Objekt-Orientierte Programmierung (OOP)** (4-6 Wochen)
📁 Ordner: `02-java-oop`

**Inhalt:** Das Herzstück der Java-Programmierung
- Klassen & Objekte
- Konstruktoren
- Vererbung (Inheritance)
- Polymorphie
- Encapsulation (private/public)
- Minecraft-Klasse-Beispiele (Mob, Item, Block)

**Abschlussprojekt:** 🎯 `ABSCHLUSSPROJEKT.md` - Zombie Kampfsimulator
**Voraussetzung:** Phase 1 abgeschlossen
**Nach dieser Phase:** Verstehst du OOP, das ist ESSENTIELL für Mods!

---

### 🟠 **Phase 3: Collections & Datenstrukturen** (2-3 Wochen)
📁 Ordner: `03-java-collections`

**Inhalt:** Arbeiten mit größeren Datenmengen
- ArrayList (dynamische Arrays)
- HashMap (Schlüssel-Wert-Paare)
- for-each Schleifen
- Iterator
- Praktische Minecraft-Beispiele

**Abschlussprojekt:** 🎯 `ABSCHLUSSPROJEKT.md` - Minecraft Inventarsystem
**Voraussetzung:** Phase 2 abgeschlossen
**Nach dieser Phase:** Kannst du komplexe Daten managed

---

### 🔴 **Phase 4: I/O & Exceptions** (1-2 Wochen)
📁 Ordner: `04-java-io`

**Inhalt:** Dateibearbeitung & Fehlerbehandlung
- Datei lesen/schreiben
- Scanner (User Input)
- Try/Catch (Exception Handling)
- Konfigurationsdateien

**Abschlussprojekt:** 🎯 `ABSCHLUSSPROJEKT.md` - Spieler-Verwaltungssystem
**Voraussetzung:** Phase 3 abgeschlossen
**Nach dieser Phase:** Kannst du mit Dateien arbeiten

---

### 🎮 **Phase 5 (OPTIONAL): Minecraft MDK** (Phase 5 existiert noch nicht 🔄)
📁 Wird später erstellt

**Inhalt:** Echte Minecraft-Mods schreiben!
- Minecraft MDK Setup
- Erste Mod erstellen
- Block, Item, Entität registrieren
- Event-Handler

**Voraussetzung:** Alle Phase 1-4 abgeschlossen
**Nach dieser Phase:** 🎉 Du hast deine ERSTE Mod geschrieben!

---

## 🚀 Wie du startest

### Option 1: Sequential (empfohlen für Anfänger)
1. Öffne `01-java-basics` in VS Code
2. Folge dem LERNPFAD.md dort
3. Nach Abschluss → öffne `02-java-oop`
4. Und so weiter...

### Option 2: Pick & Mix (wenn du bereits Erfahrung hast)
- Du kennst bereits Basics? → Starten Sie mit Phase 2
- Du kennst OOP? → Starten Sie mit Phase 3

## 💡 Tipps für den Start

1. **Öffne immer den richtigen Ordner** in VS Code
2. **Lese README.md** in jedem Ordner
3. **Folge LERNPFAD.md** Schritt für Schritt
4. **Schreib Code selbst**, nicht kopieren
5. **Mache Pausen** - 45 min lernen, 10 min Pause
6. **Experimentiere** - ändere Zahlen/Text und teste
7. **Frag bei Problemen** - es gibt keine dummen Fragen!

## 🎓 Welche Phase passt zu dir?

**Du bist absoluter Anfänger?**
→ Start mit Phase 1 (01-java-basics)

**Du kennst schon Schleifen und Variablen?**
→ Start mit Phase 2 (02-java-oop)

**Du hast Java bereits gelernt?**
→ Start mit Phase 3 (03-java-collections)

**Du willst sofort Mods schreiben?**
→ Mach erst alle Phasen 1-4, dann Phase 5!
